# 梅子の色暦

季節の景色と日本の色を紹介する、静的なウェブサイトです。HTML・CSS・JavaScriptで構成し、ビルド作業なしで表示できます。

## 主なファイル

- `index.html`：ページの文章と構成
- `style.css`：レイアウトとデザイン
- `script.js`：図鑑の表示、検索、ナビゲーション
- `data/colors.js`：69色の表示順・番号・色名・HEX・画像の対応
- `assets/`：季節写真とスウォッチ画像

## 外部リンク

InstagramはアカウントURL未設定のためInstagramトップへ、ショップはリンク先未設定の状態です。

## 公開

このリポジトリの `main` ブランチはCloudflare Pagesに接続されています。HTML/CSS/JavaScriptのみの構成なのでビルドコマンドは不要です。`main`への更新が公開ページに反映されます。
