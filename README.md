# 梅子の色暦

静的HTML/CSS/JavaScriptで作った、無料ホスティング向けの小さな色の図鑑です。

## 編集する場所

- `index.html`：ページ本文とナビゲーション
- `colors.js`：色カードの名前・読み・HEX・系統・説明・画像名
- `script.js`：検索・系統フィルター
- `style.css`：見た目
- 色のPNG画像：各色の素材

69色の正式マスターが揃ったら `colors.js` の `UMekoColors` 配列へ追加してください。候補4色は仮登録です。色コード・説明文は正式資料と照合してください。星座の例は季節の提案です。

Instagramとショップのリンク先は `script.js` の `UMekoLinks` に設定できます。
